# MUST-дашборд на сервере

```
[MUST] --RS485-- [EyeBond стик] --интернет, TCP 8899--> [сервер: dashboard.mjs] <--HTTPS-- [телефон/браузер]
```

## 1. Сервер

```bash
# скопировать папку server/ на сервер, затем:
cd server
cp .env.example .env && nano .env        # ALLOW = внешний IP дома, DASH_PASS = пароль
docker compose up -d --build
docker compose logs -f                   # ждём «логгер подключился»
```

Без Docker: `set -a; . ./.env; set +a; npx pm2 start dashboard.mjs --name must -- --no-announce`

### Firewall
Порт логгера открыть **только для дома**: протокол логгера без шифрования и пароля.
```bash
sudo ufw allow from <ВНЕШНИЙ_IP_ДОМА> to any port 8899 proto tcp
```
Порт 3000 наружу не открывать, если используете Caddy (ниже).

### HTTPS
Basic Auth без HTTPS передаёт пароль открытым текстом. Если есть домен `must.example.com`, указывающий на сервер, — Caddy:
```
must.example.com {
    reverse_proxy 127.0.0.1:3000
}
```
Нет домена — оставьте `HTTP_HOST=127.0.0.1` и заходите через Tailscale или `ssh -L 3000:127.0.0.1:3000 user@server`.

## 2. Перенаправить логгер на сервер (один раз, с Mac дома)

Сначала остановите дашборд на Mac (Ctrl+C), иначе он перехватит логгер обратно.
```bash
cd ~/Desktop/Work/Must
node announce.mjs 192.168.0.142 <IP_СЕРВЕРА>
```
Через ~1 минуту в логах сервера появится `логгер подключился`. Отправляйте один раз: каждый повтор рвёт сессию логгера.

## Если что-то не так
- **Не подключается** — `ALLOW` должен быть внешним IP дома (не 192.168…); проверьте firewall и что порт слушается: `ss -ltnp | grep 8899`.
- **В логах «чужое подключение от X»** — у провайдера сменился IP дома. Пропишите новый X в `ALLOW` и `docker compose up -d`.
- **После отключения света логгер снова в облаке** — адрес сервера у него не сохраняется: повторите шаг 2.
- **Вернуть облако SmartESS** — перенастройте сеть стика в приложении SmartESS.
